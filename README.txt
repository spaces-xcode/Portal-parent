بوابة مدرسة البيان العربية – برادفورد
=====================================

التشغيل محلياً: افتح index.html في المتصفح (يحتاج إنترنت لتحميل الخطوط والأيقونات).

النشر على الإنترنت (مجاني): ارفع المجلد كاملاً على Netlify Drop أو GitHub Pages أو Cloudflare Pages.

الدخول:
- المدير: المستخدم bayan / كلمة المرور 159101  (غيّرهما من أعلى ملف script.js)
- ولي الأمر: رمز الطالب وكلمة مروره (يضيفها المدير أو يستوردها من الإكسل)

استيراد الإكسل: يقبل ملف السجل (Al_Bayan_Student_Register.xlsx) مباشرة،
ويكفي وجود عمود Student Code (والأعمدة Password, Name, Name Arabic).

تنبيه مهم: البيانات تُحفظ داخل متصفح المدير فقط (localStorage)،
ولن تظهر لأولياء الأمور على أجهزتهم إلا بربط الموقع بقاعدة بيانات (Firebase / Supabase).
